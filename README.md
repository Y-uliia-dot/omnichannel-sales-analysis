# Omnichannel Sales Analysis

**Tools:** SQL (developed in DBeaver)  
**Type:** Educational project, IT School GoIT

## Objective
Explore online and offline retail sales to compare customer spending,
order values, product popularity, and purchasing patterns across channels.

## What the SQL covers
- Total online spending per customer.
- Combined online/offline order histories and products purchased in both channels.
- Customers meeting quantity conditions across both channels.
- Average order values for paid online orders and comparison between channels.
- Units sold, order counts, and top three products by distinct customer count.
- Price-based customer filtering and monthly analysis of above-average orders.

## SQL techniques
JOINs, aggregations, GROUP BY, DISTINCT, subqueries, CTEs,
UNION ALL, INTERSECT, filtering, and sorting.

## Files
- `Omnichannel_Sales_Analysis.sql`: 10 annotated SQL queries.

## Notes
This project was completed using the course database in DBeaver.
The original database is not included, so queries cannot be run independently.
No numerical business outcomes are claimed without the underlying query results.
